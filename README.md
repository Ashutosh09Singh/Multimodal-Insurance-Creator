# 🧠 Multimodal Insurance Creator

A GenAI-powered system that generates **insurance explanations + infographic visuals** using LLMs and diffusion models.

---

## 🚀 Overview
Multimodal Insurance Creator is an AI pipeline that combines:
- Retrieval-Augmented Generation (RAG)
- Large Language Models (LLMs)
- Text-to-Image Diffusion Models

It converts natural language insurance queries into:
✅ Structured insurance insights  
✅ Professional infographic visuals  

---

## 🎯 Problem Statement
Insurance documents are complex and hard to understand.  
This project builds an AI system that explains:

- Risk analysis  
- Coverage details  
- Cost breakdown  
- Prevention measures  

Using both **text and visuals** for better understanding.

---

## 🧠 Features

- 🔍 **RAG-based Context Retrieval**
  - Uses FAISS vector database
  - Retrieves relevant insurance knowledge

- ✍️ **AI Text Generation**
  - Powered by Gemini LLM
  - Structured JSON-style outputs

- 🎨 **Infographic Image Generation**
  - Stable Diffusion for visual explanations
  - Clean, minimal infographic style

- 🌐 **Streamlit UI**
  - Simple interactive interface
  - Real-time multimodal output
